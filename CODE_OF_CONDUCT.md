# Code of conduct

Treat contributors and users with respect. Discuss ideas and code without personal attacks. Harassment, discrimination, threats, sexualized conduct, and sharing someone else's private information are not acceptable.

This applies to repository issues, pull requests, discussions, and other project spaces. Keep feedback specific and constructive, and resolve misunderstandings in good faith.

The repository owner, [@maneeshv](https://github.com/maneeshv), may edit or remove inappropriate content and restrict participation. For conduct concerns, use a contact method listed on the owner's public profile to request a private channel. Do not post sensitive details publicly or use security advisories for unrelated conduct reports.
